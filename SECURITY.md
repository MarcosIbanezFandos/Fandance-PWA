# Security Policy

## Reporting a vulnerability

Please report security issues privately by email to
**marcosibanezfandos@gmail.com** rather than opening a public issue.
Include the steps to reproduce it and, if you can, the affected version or commit.

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## Development guidelines

The security rules every change in this repository follows (in Spanish) are in
[docs/seguridad.md](docs/seguridad.md).
